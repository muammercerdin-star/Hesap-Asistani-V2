# Hesap Asistanı V2

Otobüs seferlerinde muavin, şoför ve şirket sahibi için kasa takibi yapmaya yönelik mobil öncelikli hesap uygulaması.

## Ana özellikler

- Sefer başlatma ekranı
- Girdi / çıktı / teslim işlemleri
- Muavin, 1. şoför, 2. şoför bazlı kasa takibi
- Girdi ve çıkış kategori sistemi
- Hesap pusulası
- Döküm ekranı
- Raporlar bölümü
- WhatsApp / paylaşım odaklı sefer özeti

## Not

Bu proje Muavin Asistanı projesinden ayrıdır. Bağımsız olarak geliştirilecektir.
